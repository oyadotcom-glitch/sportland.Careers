# חיבור הלידים ל-Google Sheets

הגיליון: **לידים לרואה חשבון SmartCount**
https://docs.google.com/spreadsheets/d/1--LGELxG5FNe7ds_LWXCwScr3dl-bLK3cYE4-H6VbUo/edit

הטופס שולח כל ליד ל-Google Apps Script שמחובר לגיליון, והסקריפט מוסיף שורה.
הודעת התודה ואירוע ההמרה (Lead) מופעלים רק אחרי שהסקריפט מאשר שהשורה נשמרה.

## התקנה (פעם אחת, כ-2 דקות)

יש לבצע מהחשבון שהגיליון שייך לו (snipermediainfo@gmail.com) או מחשבון עם הרשאת עריכה.

1. לפתוח את הגיליון → **Extensions / תוספים** → **Apps Script**.
2. למחוק את הקוד שמופיע בעורך ולהדביק את כל התוכן של `Code.gs` מהתיקייה הזו. לשמור (Ctrl+S).
3. (לא חובה) בשורה `var NOTIFY_EMAIL = '';` להכניס כתובת מייל כדי לקבל התראה על כל ליד חדש.
4. **Deploy / פריסה** → **New deployment / פריסה חדשה** → בגלגל השיניים לבחור **Web app**.
   - Execute as / הפעלה בתור: **Me**
   - Who has access / למי יש גישה: **Anyone / כל אחד**
5. **Deploy** → לאשר את ההרשאות (Google יציג אזהרה "האפליקציה לא אומתה" – לבחור Advanced → Go to project. זה הסקריפט שלכם).
6. להעתיק את **Web app URL** (מסתיים ב-`/exec`).
7. להדביק את הכתובת ב-`assets/js/config.js`:
   ```js
   lead: {
     endpoint: "https://script.google.com/macros/s/XXXXXXXX/exec",
   ```

בדיקה מהירה: פתיחת כתובת ה-`/exec` בדפדפן צריכה להחזיר `{"ok":true,"service":"smartcount-leads"}`.

בשליחה הראשונה תיווצר בגיליון לשונית בשם **לידים** עם שורת כותרות.

## חשוב לדעת

- **עדכון קוד הסקריפט:** אחרי כל שינוי ב-`Code.gs` צריך Deploy → **Manage deployments** → עריכה → Version: **New version**. כך הכתובת נשארת אותה כתובת. פריסה חדשה (New deployment) יוצרת כתובת חדשה.
- **הגנות:** ולידציה של שם, טלפון והסכמה בצד השרת, מניעת כפילויות לפי מזהה ליד, חסימת הזרקת נוסחאות, ו-honeypot בטופס. הכתובת ציבורית מטבעה, ולכן אם יגיע ספאם בהיקף – אפשר להוסיף reCAPTCHA.
- **מגבלות:** Apps Script בחשבון Gmail רגיל מתאים בנוחות לנפח של דף נחיתה (מאות לידים ביום). מיילי התראה מוגבלים ל-100 ביום בחשבון רגיל.
- **הרשאות לגיליון:** מי שיש לו גישה לגיליון רואה את פרטי הלידים. כדאי לשתף אותו רק עם מי שמטפל בפניות, ולעדכן את מדיניות הפרטיות בהתאם.
